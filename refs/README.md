# References

Where we keep reference materials — PDFs of papers, screenshots of articles, notes from books, whatever.

The full source list (downloaded + need to acquire + still to grab) is in `sources.md`. Check there before adding anything new so we're not duplicating work.

## Conventions

- Name files so the source is obvious: `lastname_year_keyword.pdf`, `goldsberry_sprawlball_ch3_notes.md`, etc.
- When you cite something in `docs/`, also add it to `docs/09_references.md` so it ends up in the final report.
- Don't commit PDFs larger than ~20 MB — link to them in `sources.md` instead.
