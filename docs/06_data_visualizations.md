# Data Visualizations

**Rubric component:** Data Visualizations (50 points)
**Owner:** Cole (writing); Calder (RQ2 charts) + Marc (model outputs)
**Status:** Submitted

> Per the rubric: *Graphs that were created to support the objectives of the analysis and/or helped to develop conclusions about the data. Different than the EDA visualizations.*

The finalized data visualizations live alongside this file as **[`06_data_visualizations.pdf`](06_data_visualizations.pdf)** — eight charts grouped by research question, each paired with a paragraph of commentary. RQ1 shows the top player and team overperformers by makes above expectation; RQ2 traces how shot location and success changed across the tracking era (court density maps, court FG% maps, and zone-level attempt and FG% change); RQ3 shows the rank shift between traditional FG% and shot-quality-adjusted ranking; and a final chart compares the logistic and gradient-boosted models.

The figures are generated by [`notebooks/03_analysis/05_calder_data_visualizations.ipynb`](../notebooks/03_analysis/05_calder_data_visualizations.ipynb), which reads the model output tables in [`data/model_outputs/`](../data/model_outputs) so the charts regenerate on any machine without re-running the models.
