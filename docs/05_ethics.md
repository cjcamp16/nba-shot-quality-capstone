# Ethical Recommendations & Implications

**Rubric component:** Ethical Recommendations and Implications (50 points)

> Per the rubric: *Explanation of the implications of your research which will include recommendations that are based on an ethical approach.*

The finalized ethics writeup lives alongside this file as **[`05_ethics.pdf`](05_ethics.pdf)**. The central argument is that a shot-quality model measures only one dimension — shot-making — and says nothing about the defense, rebounding, and playmaking that make up most of a player's value, so it must never be used as a standalone verdict on a player. It grounds that point in the literature on metric over-reliance (Muller, 2018; Thomas & Uminsky, 2020) and closes with concrete recommendations for responsible use: pair it with a slate of other measures, interpret in role context, be transparent with players, and be honest about the single-season data limitation.
